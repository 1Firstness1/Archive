# Архив документов — Информационная система

## Описание
Проект представляет собой модульную информационную систему учёта и выдачи архивных документов:
1. **Бэкенд (Spring Boot REST API + Docker)** — каталог `backend`. Отвечает за аутентификацию, регистрацию, управление сессиями и работу с PostgreSQL.
2. **Настольное JavaFX-приложение (КР №2)** — каталог `javafx-client`. Полнофункциональный настольный интерфейс с авторизацией, CRUD-операциями, фильтрацией, сортировкой, статистикой и экспортом данных в XLSX/CSV.
3. **Консольное приложение (КР №1)** — располагается в каталоге `src` (корень).

Система использует СУБД PostgreSQL для надёжного хранения данных и построена по многослойной архитектуре.

## Порядок и последовательность запуска системы

> **Важно**: Если запустить только JavaFX-клиент без предварительного запуска инфраструктуры, окно приложения откроется в автономном режиме, но операции авторизации и работы с данными будут заблокированы до подключения.  
> **Правильная последовательность запуска:**
> 1. Сначала **Docker и PostgreSQL + Backend**;
> 2. Проверка доступности REST API;
> 3. Запуск **JavaFX-приложения**.

### Шаг 1. Запуск инфраструктуры (Backend + PostgreSQL в Docker)

Перейдите в каталог `backend` и запустите сервисы:
```bash
cd backend
docker compose up -d
```

Docker поднимет:
- Контейнер базы данных `archive_postgres` на порту `5432` (с автоматической инициализацией таблиц из `sql/init.sql`).
- Контейнер бэкенда `archive_backend` на порту `8080`.

Для проверки статуса контейнеров:
```bash
docker compose ps
```

Для просмотра логов:
```bash
docker compose logs -f
```

---

### Шаг 2. Запуск настольного JavaFX-клиента (КР №2)

Перейдите в каталог `javafx-client` и запустите приложение через Maven:
```bash
cd javafx-client
mvn javafx:run
```

#### Авторизация в JavaFX-приложении:
- При запуске приложения открывается окно авторизации и регистрации.
- **Стартовые учетные данные** хранятся в файле `backend/.env`:
  - **Логин**: `admin`
  - **Пароль**: `admin123`
- При необходимости новый пользователь может зарегистрироваться через вкладку **«Регистрация»**.
- После успешного входа в верхнем меню доступна кнопка **«🔑 Сменить пароль»** для обновления своего пароля через REST API.
- Если контейнеры выключены, приложение показывает предупреждающий баннер и кнопку **«🔄 Проверить подключение»** для горячего подключения без перезапуска.

---

### Шаг 3. Запуск консольного приложения (КР №1)

Оставаясь в корневом каталоге проекта:
```bash
mvn compile exec:java -Dexec.mainClass="ru.mirea.archive.Main"
```

## Функциональность JavaFX-клиента
- **Авторизация и безопасность**: вход по логину/паролю, регистрация новых пользователей, смена пароля через Spring Boot REST API.
- **Автономный режим**: корректный запуск и оповещение пользователя при недоступности инфраструктуры.
- **Полный CRUD**: создание, просмотр, редактирование и удаление запросов на документы и пользователей.
- **Поиск, фильтрация и сортировка**: по статусу, приоритету, названию и ФИО.
- **Статистика**: графическое распределение запросов по категориям, статусам и приоритетам.
- **Экспорт данных**: выгрузка в форматы XLSX и CSV (с возможностью экспорта сразу обеих таблиц по очереди).
