# Архив документов — Информационная система

## Описание
Проект состоит из двух частей:
1. **Консольное приложение (КР №1)** — располагается в корневом каталоге.
2. **Настольное JavaFX-приложение (КР №2)** — располагается в каталоге `javafx-client`.

Система использует PostgreSQL для хранения данных (подключение через JDBC) и построена по многослойной архитектуре.

## Требования
- Java 21
- Maven 3.9+
- Docker и Docker Compose

## Настройка и Запуск Базы Данных
В проекте настроен Docker Compose для автоматического развертывания PostgreSQL и создания структуры БД.

Docker автоматически выполнит скрипт инициализации БД (`sql/init.sql`). База данных `archive_db` будет доступна на порту `5432` с пользователем `artem` и паролем `1234`.


Для запуска базы данных выполните команду:
```bash
docker compose up -d
```

Для проверки статуса контейнера выполните команду:
```bash
docker compose ps
```

Для просмотра логов базы данных выполните команду:
```bash
docker compose logs -f
```

Для остановки контейнера выполните команду:
```bash
docker compose down
```

## Запуск приложений

### 1. Консольное приложение (КР №1)
Оставаясь в корневом каталоге проекта, выполните:
```bash
mvn compile exec:java -Dexec.mainClass="ru.mirea.archive.Main"
```

### 2. JavaFX-приложение (КР №2)
Перейдите в каталог `javafx-client` и запустите приложение через Maven:
```bash
cd javafx-client
mvn javafx:run
```

## Структура проекта
```
Archive/
├── docker-compose.yml        — Файл для запуска базы данных
├── pom.xml                   — Maven-конфигурация консольного приложения (КР1)
├── sql/
│   └── init.sql              — Скрипт создания структуры БД
├── src/                      — Исходный код консольного приложения (КР1)
│   └── main/java/ru/mirea/archive/
│       ├── Main.java         — Точка входа консольного приложения
│       ├── model/            — Сущности
│       ├── repository/       — Слой доступа к БД
│       ├── service/          — Бизнес-логика
│       └── ui/               — Консольный интерфейс
│
└── javafx-client/            — Проект JavaFX-приложения (КР2)
    ├── pom.xml               — Maven-конфигурация JavaFX приложения
    └── src/main/             — Исходный код JavaFX приложения
        ├── java/ru/mirea/archive/
        │   ├── MainApp.java  — Точка входа JavaFX
        │   ├── controller/   — Контроллеры окон и логика интерфейса
        │   ├── model/        — Переиспользуемые сущности
        │   ├── repository/   — Переиспользуемые репозитории
        │   └── service/      — Переиспользуемая бизнес-логика
        └── resources/
            ├── fxml/         — FXML-шаблоны интерфейса
            ├── css/          — Стили оформления (styles.css)
            └── db.properties — Параметры подключения к БД
```

## Функциональность JavaFX-клиента
- Полный CRUD для запросов на документы и пользователей.
- Поиск, фильтрация (статус, приоритет) и многоуровневая сортировка.
- Вывод статистики по категориям, статусам и приоритетам.
- Экспорт данных в форматы XLSX и CSV с выбором пути сохранения.
- Встроенная валидация данных.
- Разделение на MVC: FXML, Контроллеры, Сервисы, Репозитории.
