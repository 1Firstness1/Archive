# Теоретический справочник проекта (Backend + JavaFX)

В данном руководстве собрана ключевая теория по технологиям, паттернам проектирования и архитектурным механизмам, используемым в проекте **Архив документов**. Справочник структурирован «файл — теоретическая концепция».

---

## 1. Общие концепции программирования и ООП

### 1.1. Параметрический полиморфизм (Generics)
* **Что это:** Возможность объявлять классы, интерфейсы и методы с параметрами типа (например, `List<T>`, `Optional<T>`, `TableView<Worker>`).
* **К какому типу ООП относится:** Относится к **параметрическому полиморфизму** (Parametric Polymorphism).
* **Зачем нужно:**
  1. **Строгая типобезопасность на этапе компиляции (Compile-Time Type Safety):** компилятор не позволит положить объект не того типа.
  2. **Отсутствие ручного приведения типов:** не нужно писать `(Worker) obj`, что исключает `ClassCastException` во время выполнения.
  3. **Стирание типов (Type Erasure):** в байт-коде JVM информация о конкретном типе дженерика стирается ради обратной совместимости со старыми версиями Java.

### 1.2. Паттерн MVC (Model-View-Controller)
* **Model (Модель):** Данные и бизнес-правила (`Worker`, `DocumentRequest`, `Account`).
* **View (Представление):** Пользовательский интерфейс (файлы разметки `.fxml` и стили `.css`).
* **Controller (Контроллер):** Связующее звено, обрабатывающее действия пользователя, вызывающее сервисы и обновляющее View (`MainController`, `AuthController`).

## 2. Серверная часть (Backend на Spring Boot)

### 2.1. `BackendApplication.java`
* **IoC (Inversion of Control — Инверсия управления):** Управление жизненным циклом объектов (создание, настройка, связывание, уничтожение) берет на себя фреймворк (Spring контейнер), а не программист вручную через `new`.
* **DI (Dependency Injection — Внедрение зависимостей):** Передача зависимостей в объект извне (например, через конструктор), а не создание их внутри объекта.
* **`@SpringBootApplication`:** Составная аннотация, включающая в себя:
  - `@Configuration` — объявляет класс источником конфигурации бинов.
  - `@EnableAutoConfiguration` — включает автоконфигурацию Spring Boot на основе библиотек в `pom.xml`.
  - `@ComponentScan` — сканирует текущий пакет и все вложенные пакеты в поисках компонентов (`@Service`, `@Repository`, `@RestController`).

---

### 2.2. `controller/AuthController.java`
* **REST (Representational State Transfer):** Архитектурный стиль взаимодействия систем по протоколу HTTP с использованием стандартных методов (`GET`, `POST`, `PUT`, `DELETE`) и форматов данных (JSON).
* **`@RestController`:** Комбинация аннотаций `@Controller` и `@ResponseBody`. Означает, что возвращаемые методами данные автоматически сериализуются в JSON в теле HTTP-ответа, а не интерпретируются как имя HTML-шаблона.
* **`@RequestBody`:** Указывает Spring преобразовать входящее тело HTTP-запроса (JSON-строку) в соответствующий Java-объект с помощью библиотеки **Jackson** (`HttpMessageConverter`).
* **`ResponseEntity<T>`:** Обертка над HTTP-ответом, позволяющая явно задать HTTP-статус (`200 OK`, `400 Bad Request`, `503 Service Unavailable`), заголовки (`Headers`) и тело ответа (`Body`).
* **CORS (`@CrossOrigin`):** Cross-Origin Resource Sharing — механизм безопасности браузеров, запрещающий веб-страницам делать запросы к другому домену/порту, если сервер явно не разрешил это в заголовке `Access-Control-Allow-Origin`.

---

### 2.3. `service/AuthService.java`
* **Service Layer (Слой бизнес-логики):** Изолирует правила предметной области и логику приложения от контроллеров (API) и репозиториев (БД).
* **`@Transactional`:** Декларативное управление транзакциями:
  - Гарантирует соблюдение принципов **ACID** (Атомарность, Согласованность, Изолированность, Долговечность).
  - При возникновении непроверяемого исключения (`RuntimeException`) Spring автоматически откатит транзакцию (`rollback`), предотвращая частичную запись поврежденных данных.
* **`CommandLineRunner`:** Интерфейс Spring Boot, метод `run(String... args)` которого автоматически выполняется сразу после поднятия контекста приложения. В проекте используется для инициализации первого суперпользователя (`admin`) из `.env`.
* **Криптографическое хэширование (SHA-256):**
  - **Хэширование (One-way Hash)** — необратимое математическое преобразование произвольной строки в строку фиксированной длины (256 бит). Восстановить исходный пароль из хэша невозможно (в отличие от двустороннего шифрования).
  - При входе вычисляется хэш от введенного пароля и сравнивается с хэшем из базы:  
    `expectedHash.equals(actualHash)`.

---

### 2.4. `repository/AccountRepository.java` и `AuditLogRepository.java`
* **Spring Data JPA & Паттерн Repository:** Предоставляет готовую абстракцию для работы с таблицами БД без написания шаблонного SQL-кода.
* **Query Derived Methods (Вывод запросов по имени метода):**
  - Метод `existsByUsername(String username)` автоматически транслируется Spring Data в SQL:  
    `SELECT count(*) > 0 FROM app_accounts WHERE username = ?`.
  - Метод `findAllByOrderByCreatedAtDesc()` генерирует:  
    `SELECT * FROM audit_logs ORDER BY created_at DESC`.

---

### 2.5. `model/Account.java` и `AuditLog.java`
* **ORM (Object-Relational Mapping):** Технология отображения объектно-ориентированных моделей на реляционную модель базы данных.
* **JPA (Jakarta Persistence API) & Hibernate:**
  - **JPA** — спецификация (набор интерфейсов и аннотаций Java).
  - **Hibernate** — конкретная реализация этой спецификации.
* **Аннотации JPA:**
  - `@Entity` — класс является сущностью базы данных.
  - `@Table(name = "...")` — имя связанной таблицы.
  - `@Id` и `@GeneratedValue(strategy = GenerationType.IDENTITY)` — первичный ключ с автоинкрементом (PostgreSQL `SERIAL`).
  - `@Column` — настройки колонок (длина, уникальность, nullability).
* **`@SuppressWarnings("JpaDataSourceORMInspection")`:** Аннотация уровня исходного кода, указывающая анализатору IntelliJ IDEA отключить проверку соответствия таблиц схеме IDE.

---

### 2.6. `dto/` (Data Transfer Objects)
* **Паттерн DTO:** Объект для безопасной и экономной передачи данных по сети.
* **Почему сущности БД не отдаются клиенту:**
  - Сущность `Account` содержит приватный хэш `password_hash`. DTO `WorkerDto` намеренно не содержит этого поля, физически исключая утечку паролей по сети.
* **Зачем пустой конструктор (`no-arg constructor`):**
  - Библиотека **Jackson** использует Java Reflection: сначала создает пустой объект через конструктор по умолчанию `Class.getDeclaredConstructor().newInstance()`, а затем вызывает сеттеры для заполнения полей. Без пустого конструктора парсинг JSON выдаст ошибку `InvalidDefinitionException`.

---

### 2.7. `backend/Dockerfile` и `docker-compose.yml`
* **Контейнеризация (Docker):** Изоляция приложения вместе со всеми его зависимостями (Java JRE, библиотеки) в стандартизированный легковесный контейнер.
* **Docker Compose:** Инструмент для одновременного запуска мультиконтейнерных систем (Бэкенд + PostgreSQL).
* **Volumes (Тома данных `postgres_data`):** Механизм сохранения данных БД на хост-машине независимо от жизненного цикла контейнера (данные не сотрутся при перезапуске).

---

## 3. Клиентская часть (JavaFX Desktop Client)

### 3.1. `MainApp.java`
* **Жизненный цикл JavaFX:**
  1. `Application.launch()` — инициализация JavaFX рантайма.
  2. `init()` — подготовка ресурсов до отрисовки графики.
  3. `start(Stage primaryStage)` — запуск графического окна в UI-потоке (**JavaFX Application Thread**).
  4. `stop()` — завершение работы при закрытии окна.
* **Scene Graph (Граф сцены):** Иерархическое дерево графических узлов (`Node`).
  - `Stage` — главное окно операционной системы.
  - `Scene` — сцена, размещаемая внутри Stage.
  - Корневой узел `Parent` (например, `BorderPane`), внутри которого находятся кнопки, таблицы, текстовые поля.

---

### 3.2. `resources/fxml/main_view.fxml` и `styles.css`
* **Декларативный UI (FXML):** Язык разметки на базе XML для декларативного описания внешнего вида программы. Разделяет логику (Java) и оформление (XML).
* **Layout Panes (Контейнеры компоновки):**
  - `VBox` — вертикальное размещение элементов друг под другом.
  - `HBox` — горизонтальное размещение элементов в строку.
  - `StackPane` — наложение слоев друг на друга (используется для переключения экрана входа и рабочих вкладок).
  - `Region` с `HBox.hgrow="ALWAYS"` — эластичная распорка для прижатия кнопок к краям экрана.
* **JavaFX CSS:** Диалект CSS для оформления графических компонентов (префикс `-fx-*`: `-fx-background-color`, `-fx-font-size`).

---

### 3.3. `controller/MainController.java`
* **Инъекция разметки (`@FXML`):** Аннотация связывает переменные в Java-коде с элементами в FXML по совпадению `fx:id`.
* **Паттерн Observer (Наблюдатель):**
  - `ObservableList<T>` — специальная коллекция, которая при добавлении, изменении или удалении элементов автоматически уведомляет графическую таблицу `TableView` о необходимости перерисовки.
* **`PropertyValueFactory`:** Механизм рефлексивного связывания свойств модели с колонками таблицы: колонка `workerLoginCol` автоматически вызывает `getUsername()` у объекта `Worker`.
* **Паттерн Delegate / Factory (`setCellFactory`):** Кастомизация отображения ячеек (например, цветные бейджи ролей `ADMIN` и `USER` вместо простого текста).
* **Фоновый Heartbeat (Асинхронный опрос состояния):**
  - Использование `Timeline` и `KeyFrame` вместо блокирующего `Thread.sleep()`. Все обновления графики происходят строго в **JavaFX Application Thread**, исключая зависание окна.

---

### 3.4. `service/AuthClientService.java`
* **`java.net.http.HttpClient` (Java 11+):** Современный встроенный HTTP-клиент платформы Java, поддерживающий синхронные (`send`) и асинхронные (`sendAsync`) запросы по протоколам HTTP/1.1 и HTTP/2.
* **Fallback-паттерн (Отказоустойчивость):** Если REST API бэкенда временно недоступно, клиент автоматически пробует получить данные напрямую из базы PostgreSQL через запасной метод с прямым JDBC-запросом.

---

### 3.5. `model/AuthSession.java`
* **Паттерн Singleton (Одиночка):**
  - Гарантирует наличие строго одного экземпляра класса в памяти программы.
  - Достигается через приватный конструктор `private AuthSession()` и статический метод доступа `getInstance()`.
  - Хранит данные текущей учетной записи (логин, ФИО, роль, токен) на все время работы клиента.

---

### 3.6. `util/DatabaseManager.java`
* **JDBC (Java Database Connectivity):** Базовый стандарт взаимодействия Java-программ с реляционными базами данных.
* **Идиома `try-with-resources`:**
  - Конструкция `try (Connection conn = ...; Statement stmt = ...)`.
  - Автоматически закрывает сетевые подключения и освобождает сокеты при выходе из блока благодаря интерфейсу `AutoCloseable`, защищая от утечек памяти (Resource Leaks).

---

### 3.7. `util/ExcelExporter.java`
* **Apache POI:** Популярная Java-библиотека для чтения и записи документов Microsoft Office (в частности, формата XLSX через класс `XSSFWorkbook`).
* **Потоковый экспорт CSV:** Формирование текстового файла с разделителями (запятая/точка с запятой) с соблюдением стандарта RFC 4180 (экранирование кавычек и переносов строк).

## 4. Сводная таблица паттернов проектирования в проекте

| Паттерн | Где применяется | Назначение в проекте |
|---|---|---|
| **MVC** | `main_view.fxml`, `MainController`, `Worker` | Разделение интерфейса, контроллера и данных |
| **DTO** | `WorkerDto`, `AuthRequest`, `HealthResponse` | Передача данных по сети без раскрытия структуры БД и хэшей паролей |
| **Singleton** | `AuthSession` | Хранение единого состояния авторизованного пользователя |
| **Repository (DAO)** | `AccountRepository`, `AuditLogRepository` | Абстракция доступа к таблицам БД |
| **Observer** | `ObservableList`, `selectedItemProperty` | Автоматическое обновление UI при изменении данных и вкладок |
| **Factory / Delegate** | `setCellFactory` | Генерация кастомных визуальных ячеек (цветных бейджей ролей) |
| **Fallback** | `AuthClientService` | Запасное чтение данных через JDBC при сбое REST API |
| **IoC / DI** | Spring Boot (`@Autowired` через конструктор) | Управление зависимостями и компонентами бэкенда |
